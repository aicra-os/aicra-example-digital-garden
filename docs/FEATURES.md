# 🎯 Proje Kapsamı (Versiyon 1.0)

Bu belge, "Dijital Bahçe" projesinin ilk kullanılabilir sürümünde yer alacak temel özellikleri tanımlar.

### Kapsamdaki Özellikler (In-Scope)

*   **Not Oluşturma:** Kullanıcılar, Markdown formatında basit metin notları oluşturabilmelidir.
*   **Not Görüntüleme:** Kullanıcılar, oluşturdukları tüm notları bir liste halinde görebilmeli ve tek bir nota tıklayarak içeriğini okuyabilmelidir.
*   **Basit API:** Tüm bu işlemlerin yapılabilmesi için temel bir REST API altyapısı kurulmalıdır.

### Kapsam Dışındaki Özellikler (Out-of-Scope for v1.0)

*   Kullanıcı kimlik doğrulama
*   Notları etiketleme veya kategorize etme
*   Gelişmiş arama
*   Notlar arasında link oluşturma
